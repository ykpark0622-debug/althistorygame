2. 새 배포 ZIP의 압축을 풀고, 폴더 안의 파일·하위 폴더를 기존 저장소 루트에 같은 경로로 교체하세요. 루트에서 index.html이 보여야 합니다.

4. 이번 2.0 → 2.1 업데이트는 DB 변경이 없습니다. Supabase SQL을 추가로 실행할 필요가 없습니다. 1.x에서 처음 V2로 올리는 경우에만 기존 UPDATE-GUIDE.txt의 V2 마이그레이션 단계를 확인하세요.

7. 지도 제목에 61,940개 지역이 보이고, 휠 확대·축소/드래그 이동/‘프랑스’ 버튼/‘세계’ 버튼/지역 검색이 동작하는지 확인하세요.
8. 편집기 → 지도·초기 영토에 기존 두 지도와 ‘세계 세부 지도 · 현대 행정구역’이 함께 표시되는지 확인하세요.

참고
- map-templates.js에는 큰 지도 데이터가 포함되어 있으므로 이전 파일 일부만 바꾸지 말고 새 파일 전체를 업로드하세요. 브라우저 최초 로딩이 이전보다 길 수 있습니다.
- examples/는 시나리오가 따로 들어 있는 폴더입니다. 프로그램의 첫 화면은 계속 빈 작업 공간으로 시작합니다.
- standalone.html은 지도와 편집기가 포함된 오프라인 빈 프로그램입니다. 온라인 사이트 실행에는 index.html과 연결된 JS/CSS가 사용됩니다.
- MAP-SOURCES.md, tools/map-source/licenses/, tools/map-source/world-detailed.json은 출처·이용 조건과 가공 지도 데이터입니다. 재배포 시 함께 보관하세요. 지도 안의 ‘지도 안내·출처’에도 국가별 정보를 넣었습니다.
- 기존 시나리오의 지도 두 개, 저장 형식과 커뮤니티 기능은 유지됩니다. 새 지도는 새 ID를 쓰므로 기존 영토 연결을 자동으로 변환하지 않습니다.
- 이 지도는 현대 지역 경계입니다. 1592년이나 1733년의 영토·국경은 시나리오 작성자가 별도로 구성해야 합니다.

로컬 확인
Node.js가 있으면 이 폴더에서 node serve.cjs 실행 후 http://127.0.0.1:8137/index.html 을 여세요.
Node.js 없이 확인하려면 standalone.html을 브라우저로 열고 시나리오 JSON을 불러오세요.
