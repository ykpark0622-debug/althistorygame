- 지도 소유·점령·영향권·표식 및 조건, 레이어 해제
- 치세의 동적 분야 카드, 연초/정산 규칙 순서, 지연 효과
- 돌발 대응 중복 추첨 억제와 RETURN 후 치세 카드 복귀
- 시나리오/지도/진행 변조 자료 및 잘못된 입력의 거부
- 이름 치환·HTML 이스케이프와 최종 선택 결과문
- 기존 로컬 저장 공간·JSON/파일/URL 실패 시 작업 유지
- 단일 HTML의 원고/이름/지도 표식 등 개인 입력 제외
- 갤러리 좋아요 목록의 전역 정렬/검색/페이지 분할(모의 서버)

- 기존 V1 흐름도 연결 유지, 치세 연도·돌발 연결의 구분

실제 브라우저에서도 확인
- 세종 연대기 시작~엔딩, 새로고침 후 복원, 기준 지도와 차이 0개
- 지도 편집기의 지역 선택→초기 소유/점령/영향권/표식 폼 연결
- 프랑스 치세: 3분야 선택 전 정산 잠금, 선택 후 활성화
- 이탈리아 원정+동맹 조합→밀라노 점령→다음 해
- 1개 분야 선택 상태에서 새로고침 후 선택 완료 유지
- 마지막 조건부 협상→별도 엔딩→기준 지도와 차이 1개
- AI 미리보기의 기존 원고/치세/지도 지역 ID 포함
- 치세 흐름도의 진행 안내와 일반 카드/돌발 연결 구분

검증하지 않은 운영 범위
- 자동화 브라우저의 URL 보안 정책이 file:// 직접 열기를 차단하여 단일 HTML의 로컬 파일 방식 실기동은 미확인. 해당 번들은 VM 실행/소스 일치/내보내기 검사를 통과했다.
- 실제 Supabase에 SQL 실행 및 데이터 마이그레이션
- 실제 Google 로그인, 온라인 작품 업로드/신고/관리자 동작
- GitHub 업로드 및 Vercel 운영 배포
- 모든 브라우저·모바일 기기의 실기기 호환성

운영 설정은 기존 파일을 유지했다. SQL과 갤러리는 오프라인 코드/모의 검사이며 운영 서버 성공으로 보고하지 않는다.
