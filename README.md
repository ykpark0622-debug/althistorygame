# 역사의 갈림길 — 선택지 게임 메이커 + 지도 제작·공유

**v2.13.1 선택 표시 해제:** 바다나 지도 밖 빈 공간을 누르면 선택한 지역의 윤곽선·임시 지명과 국명 선택 테두리가 사라집니다. 작업 국가·영토·저장된 국명 위치·여러 지역 선택은 유지합니다. [업데이트 적용법](UPDATE-V2.13.1.md)

**v2.13 전체화면·지도 설정:** 상단의 전체화면으로 게임을 넓게 보고, 지도 작업실의 전체화면 버튼으로 편집 공간을 화면 전체에 펼칩니다. 작업실을 열면 지도 설정이 먼저 보이며, 설정 변경·국가 선택 후에도 스크롤과 지도 위치를 유지합니다. [업데이트 적용법](UPDATE-V2.13.1.md)

**국명 표시 개선:** 모든 국명에 반투명 배경을 넣고, 국명 위치 편집에서는 선택한 국명에만 얇은 테두리를 표시합니다. 확대해도 배경 여백과 테두리 두께가 화면 크기를 유지합니다.

**역사 지도10선:** 전국칠웅·후한 군벌·한반도 삼국·30년 전쟁·1914·1933·빅토리아 시대·이탈리아·1803년 유럽을 추가했습니다. [지도 설명·출처·한계](HISTORICAL-ATLAS-10.md) · [역사 지도 둘러보기](historical-atlas.html)

버전 2.13.1-community: **국가 목록형 지도 작업실**을 적용했습니다. 왼쪽에서 국가를 검색·생성·선택하고, 오른쪽 지도에서 드래그 칠하기·여러 지역 선택·국명 위치 편집을 합니다. 지도에 초점을 두고 WASD로 이동하며 Shift로 빠르게 이동합니다. 국가를 고르는 모든 창에서 이름·ID 검색을 지원합니다. [지도 작업실 사용법](MAP-MAKER.md)

첫 화면의 **기록 삭제하기**에서 해당 시나리오의 브라우저 저장 사본과 자동·수동 진행, 발견한 엔딩을 삭제할 수 있습니다. 확인창에서 취소하면 유지합니다. 다른 작품의 저장, 지도 작업실의 지도, 직접 보관한 JSON과 갤러리 작품은 지우지 않습니다. [시작 화면 사용법](STARTUP.md)

지도 작업실의 색상표·팔레트, 국가 이름/ID 검색, 백지도 만들기와 되돌리기, 기존 국가 재색칠, 국명 드래그·저장은 그대로 사용할 수 있습니다. 지도·JSON·갤러리·시나리오에서 편집한 색상과 국명 위치가 이어집니다. 기존 지역 지도·시대 기본안과 시나리오를 유지합니다. [지도 제작기 사용법](MAP-MAKER.md) · [역사 지도 5종](HISTORICAL-MAP-SOURCES.md)

- **이어서 하기:** 이전 원고와 그 원고의 저장된 진행을 불러옵니다. 선택하기 전에는 저장 지도 자산을 요청하지 않습니다.
- **처음부터 시작하기:** 같은 시나리오를 새 진행으로 시작합니다. 이름을 묻는 시나리오는 이름을 정해 시작할 때 자동 저장이 새 진행으로 바뀝니다. 이름 입력을 사용하지 않는 시나리오는 바로 새 진행을 시작합니다. 시나리오 원고, 별도 수동 저장·발견한 엔딩·저장한 지도는 유지합니다.
- **새 시나리오·다른 시나리오:** JSON 가져오기, 새 원고 만들기, 예제 링크, 갤러리에서 열기는 기존처럼 사용할 수 있습니다. 이전과 다른 시나리오 주소로 방문하거나 갤러리에서 새 원고를 직접 열면 지정한 원고를 엽니다. 이전 시나리오와 같은 주소를 다시 열면 시작 방법을 선택합니다.
- **갤러리에서 돌아오기:** 일반 초기 화면 이동은 시작 방법을 표시합니다. 갤러리에서 작품의 플레이 버튼을 직접 누르면 해당 작품을 엽니다. 지도 가져오기도 기존처럼 사용할 수 있습니다.
- 미완성으로 저장한 초안에는 **작성하던 시나리오로 돌아가기**를 표시합니다. 이전 데이터가 없는 첫 방문에는 일반 초기 화면을 표시합니다.

**지역 지도 → 시대 기본안 → 직접 영토 편집** 순서로 지도나 시나리오를 만듭니다. v2.3 지도 공유 SQL을 이미 적용한 사이트는 추가 SQL 없이 웹 파일과 새 `assets/maps/` 폴더를 함께 교체하세요. 지도 공유 DB 업데이트를 아직 하지 않은 기존 사이트는 `supabase/migrate-v2.3-maps.sql`을 먼저 적용합니다. 기존 시나리오와 좋아요·신고 정책은 유지됩니다.

- 상단 **지도 만들기**에서 사건 없이 지도를 만들고 저장·JSON 가져오기/내보내기를 할 수 있습니다. 시나리오 원고와 별도로 저장됩니다.
- 갤러리의 **지도** 분류에서 공개 지도를 받아 편집하거나 새 시나리오의 바탕으로 사용합니다. **이 지도로 시나리오 만들기**는 새 초안을 시작하므로 기존 원고는 JSON으로 보관하세요.
- 지도 제작은 기존 지역 구획의 소유권·점령·영향권·설명과 국가 이름·색을 바꿉니다. 경계선을 새로 그리는 기능은 포함하지 않습니다.

- 첫 화면의 **지역·시대부터 지도 만들기** 또는 편집기의 **지도·초기 영토**에서 시작합니다.
- 동아시아 / 유럽과 지중해 / 아시아 전체 / 북아메리카 / 남아메리카 / 세계 중 하나를 고릅니다. 동아시아는 1419·1592·1754·현대, 나머지는 1754·현대 기본안을 제공합니다.
- 지역을 누르거나 빠른 칠하기로 소유권·점령·영향권·표식을 수정하고, 국가 이름과 색상도 바꿀 수 있습니다. 시대별 배치는 역사적 국경을 정밀 복원한 자료가 아닌 편집용 초안입니다. [REGIONAL-MAPS.md](REGIONAL-MAPS.md)
- `index.html?scenario=examples/imjin-world.json`은 동아시아 1592년 기본안의 임진왜란 연대기, `examples/regional-europe-demo.json`은 유럽 지역의 가상 치세 예제입니다.
- 휠 확대·축소, 드래그 이동, WASD 이동, 국가 이동과 지역 검색은 선택한 지도 범위 안에서 작동합니다. **전체 보기**는 그 지역의 처음 화면으로 돌아갑니다. 선택지의 여러 영토 변화는 ‘지역 이름 외 N개 지역에 변화’로 묶어 표시합니다.
- 같은 범위에서 수정한 초기 배치는 시대를 바꾸어도 유지합니다. 범위 밖 초기 배치를 제외할 때는 개수를 확인하며, 범위 밖 사건 효과·조건이 남아 있으면 변경을 보류합니다. 기존 세 가지 지도 ID는 호환용으로 유지합니다.
- 세계 경계는 geoBoundaries CGAZ ADM2와 유럽 일부 ADM3/4, 지형은 Natural Earth 1:10m입니다. **현대 행정구역이며 역사적 국경이 아닙니다.** 국가별 크기·자료 연도·상세도가 다릅니다.
- 지도 안내·출처에는 국가별 원출처와 라이선스가 포함됩니다. 배포할 때 [MAP-SOURCES.md](MAP-SOURCES.md)와 `tools/map-source/licenses/`를 함께 보관하세요. 지도 데이터의 조건은 프로그램 코드·창작 시나리오와 구분합니다.
- 지도 재생성은 [tools/DETAILED-MAP-BUILD.md](tools/DETAILED-MAP-BUILD.md)를 참고하세요. 일반 사이트 배포에는 GIS 도구나 Node 설치가 필요하지 않습니다.

수치와 선택으로 엔딩이 갈리는 텍스트 게임을 만들고(AI로 만들기 포함), 플레이하고, 갤러리에서 다른 사람과 주고받는 웹사이트입니다. V2는 사건형 진행에 더해 지도와 연차별 분야 결정을 지원합니다. 기존 V1 원고도 그대로 불러옵니다.

- 처음 설치: **[SETUP.md](SETUP.md)** 를 순서대로 따라 하세요 (Supabase → Vercel → 구글 로그인 → 관리자 등록).
- `config.js`를 비워 두면 갤러리 없이 만들기·플레이만 하는 정적 사이트로 동작합니다.
- 빌드 과정·npm 설치가 없습니다. 파일을 고쳐 GitHub에 올리면 Vercel이 그대로 배포합니다.
- 기존 V1·V2 갤러리는 `supabase/migrate-v2.3-maps.sql`을 적용합니다. 적용 후에는 오래된 `migrate-v2.sql`을 다시 실행하지 마세요. 새 설치는 갱신된 `supabase/schema.sql` 전체를 사용합니다.
- 시나리오를 새로 만들 때 진행 방식과 지도 틀을 선택하세요. AI 요청문에는 선택한 지도에 실제로 있는 지역·국가 ID가 포함됩니다. AI 응답은 로컬에서 JSON을 추출하고 형식 검사합니다. AI 서비스 호출이나 API 키는 필요하지 않습니다.
- 갤러리는 V1/V2·연대기/치세·지도 이름을 표시합니다. 완성한 시나리오를 JSON으로 내보낸 뒤 Google 로그인 → 갤러리 → 내 시나리오 올리기 → 파일 선택으로 공유할 수 있습니다.
- 지도는 게임용 구획입니다. 당시 국경을 정확히 재현한 사료로 보지 말고 지도 안내와 시나리오 설명을 함께 확인하세요.
- 기존 두 지도의 도형은 제공된 시연판의 Natural Earth 기반 현대 지역 구획을 재사용·집계했습니다. 당시의 국경·실효 지배를 단순화합니다. 웹 버전은 같은 사이트의 지도 JSON을 필요할 때 받고, 단일 HTML은 도형을 포함해 오프라인으로 작동합니다. 지도 서비스 API나 API 키는 사용하지 않습니다. [Natural Earth 이용 조건](https://www.naturalearthdata.com/about/terms-of-use/)에 따라 해당 원자료는 퍼블릭 도메인입니다.
- `examples/chronicle-sejong.json`은 지도 사건형, `examples/reign-france.json`은 지도 연차 통치형 예제입니다. 첫 화면에서 JSON을 불러오거나 해당 예제 링크로 시작할 수 있습니다.

버전 2.12.0-community · 2026-10-23

연초 규칙은 해당 해에 들어갈 때 적용합니다. 즉시 엔딩·돌발 사건의 조건과 확률은 다음 선택(또는 정산)을 마친 상태에서 판정합니다. 기준 경로 비교는 작성자가 `historical: true`로 표시한 선택들을 따른 최종 지도이며, 현재 장면과 같은 연도의 실제 국경을 자동으로 복원하는 기능은 아닙니다.

개발 확인은 Node.js에서 `node run-tests.cjs`로 단일 HTML 재생성과 기능 검사를 실행합니다. 일반 배포에는 Node.js나 npm 설치가 필요하지 않습니다. 로컬 HTTP 미리보기는 `node serve.cjs`입니다.
