역사의 갈림길 2.0 업데이트 안내

이 파일들은 사용자가 제공한 GitHub 전체 압축본(1.2.0-community)을 기준으로 수정한 배포용 프로그램입니다. 원본 ZIP과 현재 운영 사이트는 변경하지 않았습니다.

먼저 시험하기
1. standalone.html을 브라우저에서 열면 설치 없이 프로그램을 사용할 수 있습니다.
2. examples/chronicle-sejong.json을 불러오면 연대기와 지도 변화를 시험합니다.
3. examples/reign-france.json을 불러오면 분야별 결정·정산·다음 해 진행을 시험합니다.
4. 시나리오 편집 → 기본 설정에서 연대기/치세, 지도 탭에서 템플릿/초기 영토, 치세 탭에서 분야/연도를 편집합니다.
5. 사건·선택지 또는 흐름도 카드를 열어 결과문, 기준 역사, 수치/기록/지도 효과와 조건을 바꿉니다.

원고는 프로그램과 분리되어 있습니다. 프로그램의 기본 상태 및 프로그램 내려받기는 빈 시나리오로 시작하며, 예시는 별도 JSON입니다.

기존 웹사이트 업데이트
1. 현재 GitHub 파일과 Supabase 데이터를 백업해 두세요.
2. 기존 Supabase 프로젝트의 SQL Editor에서 supabase/migrate-v2.sql만 실행합니다.
   - 기존 계정/시나리오/좋아요/신고/RLS 정책을 유지하면서 V1/V2 형식과 목록 표시 정보를 지원합니다.
   - 새 프로젝트를 만드는 경우에만 supabase/schema.sql 전체를 사용합니다.
3. 압축 안의 파일을 기존 GitHub 저장소의 같은 위치에 반영합니다.
   - index.html, app.js, engine.js, editor.js, flowchart.js, ai-helper.js,
     gallery.html, gallery.js, flowchart.css, community.css, standalone.html 등 수정 파일
   - map-templates.js, map-view.js, map-view.css와 examples/ 등 추가 파일도 모두 포함합니다.
   - 기존 config.js의 연결 설정과 GitHub Secrets는 유지합니다.
4. GitHub 연동 Vercel 자동 배포를 쓰고 있다면 변경 반영 후 배포 결과를 확인합니다.
5. 기존 V1 원고 열기/이어하기와 새 V2 예시의 업로드/플레이를 각각 확인합니다.

이번 작업에서는 실제 운영 DB의 SQL 실행, Google 로그인, 온라인 게시물 업로드, GitHub 업로드·배포를 수행하지 않았습니다. 로컬 프로그램과 검증된 배포 파일을 제공한 상태입니다.

기존 기능과 호환 범위
- V1 원고를 열었다는 이유만으로 V2로 바꾸지 않습니다.
- 지도나 치세를 켜면 V2가 됩니다. 게임 규칙을 바꾼 원고에 이전 회차의 진행을 억지로 붙이지 않습니다.
- 기존과 같은 원고라면 브라우저 저장 형식/저장 공간을 유지해 이어하기를 지원합니다.
- 치세 도중 선택한 분야, 확률 상태, 지도와 정산도 저장·복원합니다.
- 자동/수동 저장은 접속한 브라우저 안에 있습니다. Google 로그인은 진행을 기기 사이에 동기화하지 않습니다.
- AI는 외부 서비스에 요청문을 복사하고 답변을 가져오는 방식입니다. API 호출이나 API 키는 추가하지 않았습니다.
- 연초 규칙은 해당 해에 들어갈 때 적용되고, 즉시 엔딩/돌발 추첨은 다음 선택 또는 정산 후에 판정합니다.
- 기준 경로 비교는 작성자가 역사 표시를 한 선택을 따라 계산한 최종 지도와의 비교입니다.

지도 안내
동아시아 1419년(124개 지역), 세계 1754년(167개 지역)을 포함합니다. 제공된 시연판의 Natural Earth 기반 데이터를 재사용했습니다. 현대 행정구역을 묶은 게임용 구획이므로 정확한 시대별 국경을 재현한 사료는 아닙니다. 외부 지도 라이브러리나 지도를 내려받지 않아도 실행됩니다.

개발자 확인
- node run-tests.cjs: 단일 HTML 재생성 후 전체 자동 검사
- node build.cjs: 수정한 JS/CSS를 standalone.html에 반영하고 배포 명세 갱신
- node build-maps.cjs: tools/map-source/의 원자료로 지도 파일 재생성
- node serve.cjs: http://127.0.0.1:8137/index.html 로컬 미리보기
- SCHEMA-V2.md: V2 데이터 구조와 엔진 API
- README.md / SETUP.md: 구조와 배포/DB 안내

주요 수정
- 좋아요 목록의 정렬·검색·페이지 분할
- AI 요청문 미리보기/복사 내용 일치
- AI 답변의 설명·주석 중괄호 때문에 JSON 추출이 실패하는 문제
- 기본 이름 표시 일치
- 흐름도 배치 저장, 주요 ID 변경 시 참조 갱신
- 마지막 선택의 결과문과 정산 기록 표시
- 단일 HTML의 지도 포함·개인 원고 제외·오프라인 표시 유지
