# 임진년의 갈림길 — 예시 시나리오

역사의 갈림길 **v2.2의 세계 세부 지도**에서 플레이하는 별도 JSON 시나리오입니다. 프로그램 소스나 이전 예제를 교체하지 않습니다.

## 열기

1. v2.2 프로그램에서 **시나리오 열기 → JSON 파일 가져오기**를 선택합니다.
2. `imjin-world.json`을 고릅니다. 현재 작업 중인 시나리오가 있다면 먼저 JSON으로 내보내 보관하세요.
3. 국왕 이름을 입력하거나 **선조 이름으로 시작**을 누릅니다.
4. 지도 오른쪽의 **조선**을 누르면 한반도로 이동합니다. **세계**는 전체 지도, **지명**은 지역명 표시 전환입니다. 휠로 확대·축소하고 드래그로 이동합니다.

기존의 ‘프랑스’ 버튼은 그 예제의 플레이 국가 이름입니다. 지도에서 바라보는 위치와 관계없이 현재 시나리오의 `map.playerCountry`를 따라갑니다. 이 시나리오는 내부 국가 ID `joseon`의 표시 이름을 ‘조선’으로 지정하고 남북한 지역 모두 같은 소유국으로 묶었습니다. 국가 이름을 바꿀 때에는 **플레이 국가와 표시 이름을 함께** 설정하세요.

서버에서 예제를 직접 열려면 `index.html?scenario=examples/imjin-world.json`을 사용합니다. 지역·시대 지도 템플릿이 없는 이전 프로그램에서는 열 수 없습니다. 로컬 `127.0.0.1` 주소는 이 컴퓨터에서 미리 보는 주소입니다.

## 구성과 편집

- **연대기 모드**, 1591~1598년과 가상 후일담. 한 번 플레이하면 대략 12~15개 장면/대응을 선택합니다.
- 전체 19개 사건 정의: 본편·조건부 장면 16개, 돌발 대응 3개.
- 수치: 재정 / 민심 / 군사 / 외교.
- **시나리오 편집**에서 사건·선택지·수치 효과·조건·확률·엔딩을 바꾸고 JSON으로 내보낼 수 있습니다. **분기 흐름도**에서는 본편 연결과 조건부 장면, 돌발 사건의 복귀를 확인하세요.
- `events[].choices[].next`는 다음 장면, `when`은 등장/선택 조건, `effects`는 수치 변화, `setFlags`는 이후 분기의 기억, `territory`는 소유권·점령·표식의 변화입니다.
- 원본 집필용 생성기는 `tools/make-imjin-sample.cjs`입니다. JSON을 직접 편집한 뒤 생성기를 다시 실행하면 JSON 내용이 재생성되므로, 편집 결과는 별도 이름으로 보관하거나 생성기에도 반영하세요.

전쟁 전 대대적 준비와 길목 방어를 **둘 다** 고르면 추가 방어 장면이 열립니다. 1597년에 함대를 보전하면 수군 재건 장면을 건너뛰고, 파직·패전 경로를 고르면 명량의 재건 장면이 나옵니다.

돌발 사건은 해당 조건을 만족하는 **일반 선택 직후** 판정하고, 대응을 마치면 원래 다음 사건으로 돌아갑니다. 각각 한 번만 발생합니다. 이미 항복·할양·철수로 결론 난 뒤에는 발생하지 않도록 설정했습니다.

| 돌발 사건 | 조건 | 확률 |
|---|---|---|
| 피란민의 빈 솥 | 전쟁 중 민심 45 이하 | 선택 후 35% |
| 진창에 멈춘 군량 | 전쟁 중 재정 25 이하 | 선택 후 30% |
| 돌아오지 않은 군역 | 1597년 이후 전쟁 중 민심 35 이하 | 선택 후 40% |

## 결말 — 아래는 조건 설명과 스포일러입니다

| 결말 | 연결되는 결정 |
|---|---|
| 일본의 완전한 승리 | 한성 잔류 → 왕실 위기에서 항복 |
| 대명일본화평조건의 수락 | 강화교섭에서 일본 요구 전면 수용을 청함 |
| 명과 일본의 협약 | 명에게 교섭 위임 → 남부 두 도 할양 묵인, 또는 장기전 중 할양 수락 |
| 조선의 승천 | 충분한 전쟁 준비 → 둔전·수운 복구 → 원정 계획 → 함대 보전 → 원정 회의 → 수년의 대마도·규슈 원정 |
| 다시 일어서는 조선 | 일본군 철수 후 재정 30 이상, 민심 55 이상 유지 |
| 피로스의 승리 | 일본군은 철수했지만 회복 조건에 못 미친 경우 |

원정 회의의 조건은 **원정 계획·둔전/수운·작전 가능한 수군·1597년 함대 보전**을 모두 갖추고 **군사 80 / 재정 35 / 민심 50 / 외교 60 이상**입니다. 군사 수치만 높아서는 열리지 않습니다. 추가 결말 ‘다시 일어서는 조선’은 해외 정복 없이도 나라를 잘 지키고 복구한 플레이를 보상합니다.

## 역사와 창작의 경계

등장인물은 황윤길, 김성일, 유성룡, 신립, 이일, 광해군, 이항복, 이순신, 원균, 곽재우, 휴정, 권율, 이여송, 심유경, 황신, 고니시 유키나가, 가토 기요마사, 진린, 도요토미 히데요시, 소 요시토시 등 실존 인물입니다. 익명의 지방관·군관은 전쟁의 상황을 설명하는 역할이며 새 역사 인물로 설정하지 않았습니다. 인물의 말과 의사결정은 원문 인용이 아닌 창작입니다.

1590년 파견된 통신사의 1591년 귀환, 1592년 침략과 피난·분조·수군 및 의병 활동, 1593년 평양 수복, 명·일 강화교섭, 1597년 재침과 수군의 위기, 1598년 히데요시 사망·철군이라는 큰 흐름을 참고했습니다. ‘기준’으로 표시한 선택은 이러한 역사적 방향을 단순화한 비교 경로입니다. 수치 결과·지도 전체·돌발 사건·개별 인과까지 실제 역사와 같다는 뜻은 아닙니다.

전면 항복, 일본 요구 전부 수용, 남부 두 도 할양, 대마도·규슈 지배는 **실제로 성립하지 않은 대체역사**입니다. 규슈의 지배는 1598년 즉시 정복이 아니라 여러 해의 전쟁과 일본 내부 분열까지 성립했다고 가정하는 극단적 후일담입니다. 원정의 가능성을 역사적으로 입증하거나 현실의 정복을 긍정하는 설명으로 읽지 않도록 했습니다.

지도에는 407개 현대 남북 지역을 조선으로 묶고 일본군 점령과 철수 등을 표시했습니다. 의주는 데이터의 `Uiju`를 사용하며 신의주와 구별합니다. 이름이 같은 일본의 쓰시마시와 대마도는 좌표로 구분했습니다. 남부 두 도·네 도와 규슈의 영역은 현대 지역 중심점으로 고른 시각적 근사치입니다. 동아시아로 자른 지도에 1592년 무렵의 조선·명·일본과 주변 세력을 대략 구분했습니다. 자료가 부족한 곳은 미설정으로 남기며 편집기에서 고칠 수 있습니다. 16세기 세계 정치지도를 정밀 복원한 것은 아닙니다.

기본 지도 데이터의 출처와 이용 조건은 프로그램의 `MAP-SOURCES.md`와 지도 안내에 포함되어 있습니다. 이 JSON은 지도 도형을 중복 배포하지 않고 템플릿 지역 ID만 참조합니다.
