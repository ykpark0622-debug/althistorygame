# 갤러리에 올릴 지도 5종

이 폴더의 *.map.json은 지도 문서입니다. 이야기·사건·전쟁 시스템이 포함된 시나리오 파일과 다릅니다.

1. 사이트에서 지도 만들기/지도 작업실을 엽니다.
2. 지도 JSON 가져오기를 누르고 *.map.json 하나를 선택합니다. 초기 화면의 파일 가져오기로 열어도 됩니다.
3. 지도와 설명을 확인하고 제목·영토·플레이어 국가를 원하는 대로 수정합니다.
4. 갤러리에 공유를 누르고 로그인하여 게시합니다.
5. 이 지도로 시나리오 만들기를 누르면 선택한 국가의 새 이야기 초안을 쓸 수 있습니다.

유럽 파일은 europe-balanced,세계 파일은 world-balanced를 참조합니다. 기존 균형 지도가 있는 v2.7 사이트에서도 가져올 수 있도록,새 역사 템플릿 ID가 아닌 기존 지형+전체 영토 배치로 만들었습니다. 파일당 1MiB 미만입니다.

별도로 사이트 자체에 기본안을 설치하면 ①유럽과 지중해→②1444/1648년 또는 ①세계→②1550/1914/1939년을 선택할 수 있습니다.

| 유럽 15세기 · 1444년 | 1444년 무렵 | 2,431 | 106 |
| 유럽 17세기 · 1648년 | 1648년 베스트팔렌 조약 이후 | 2,431 | 75 |
| 세계 16세기 · 1550년 | 1550년 무렵 | 5,939 | 174 |
| 제1차 세계대전 전야 · 1914년 | 1914년 7월, 유럽 전쟁 발발 직전 | 5,939 | 137 |
| 제2차 세계대전 전야 · 1939년 | 1939년 8월, 폴란드 침공 직전·중일전쟁 진행 중 | 5,939 | 149 |

출처·라이선스·근사 배치의 한계는 지도 설명과 HISTORICAL-MAP-SOURCES.md에 있습니다. 특히1550년의 여러 공동체 구분은 실재 단일 국가가 아닌 자료 공백을 나타내는 편집 단위입니다.
